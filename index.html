Custom Hexapod Robot

2026 IN PROGRESS

project-2-full.mp4

A six-legged robot built entirely from scratch — featuring a hand-designed schematic, hand-soldered electronics, and a 3D-printed shell. Each leg has 3 degrees of freedom, driven by 18 MG servo motors through PCA9685 driver boards, with an onboard ESP32-CAM handling control and camera functionality.

Software development is ongoing. I'm developing and testing different gait patterns to evaluate how locomotion can adapt across different types of terrain. I'm also building out remote video streaming from the onboard camera to a PC, providing the foundation for real-time object detection, with future plans to explore ML-based terrain-adaptive gait selection.

Tech Stack

ESP32-CAM Embedded C/C++ Schematic Design 3D Printing

Key Features

  • 3 degrees of freedom (DOF) per leg, 18 MG servos total, driven via PCA9685 PWM driver boards over I2C
  • Fully custom, hand-soldered electronics and schematic — no pre-built robot kit or PCB
  • ESP32-CAM as the onboard controller and camera source for future object detection and streaming
  • Actively developing and testing gait algorithms for adaptive locomotion across different terrain

MT-CPC-VRP: Optimization Research

2026 RESEARCH IN PROGRESS

project-4-full.jpg

Research project conducted as part of my role as an Algorithms & Machine Learning Research Assistant at Mount Royal University. The research focuses on a multi-trip, profit-maximizing vehicle routing problem in which orders become available for pickup at the depot on their respective release dates.

The solver framework was independently designed and implemented, incorporating several solution approaches: an exact CPLEX (DOcplex) optimization model, a greedy singleton baseline, multi-stage dynamic programming, and beam search. The exact model is used to establish optimal solutions for benchmark instances, providing a reference against which the alternative approaches can be validated and benchmarked.

I'm currently implementing an Adaptive Large Neighborhood Search (ALNS) algorithm, with future plans to incorporate machine learning to guide the search. Large-scale simulations and computational experiments are conducted using the Fir supercomputer.

Tech Stack

Python IBM ILOG CPLEX DOcplex SLURM HPC (Fir)

Key Features

  • Shared solver framework integrating an exact CPLEX model, greedy singleton baseline, multi-stage dynamic programming, and beam search.
  • Exact optimization model used to establish optimal reference solutions on benchmark instances, providing a basis for validating and comparing alternative approaches.
  • Large-scale computational experiments and solver benchmarking on the Fir supercomputer.
  • Adaptive Large Neighborhood Search (ALNS) implementation underway, with machine learning-guided search planned as a future extension.

Search & Optimization for Embedded Robotic Vision

2026 EXPLORATORY IN PROGRESS

project-5-full.jpg

An experimental project exploring how classical search and optimization algorithms can be applied to vision-related tasks on resource-constrained robotic hardware. Using the ESP32-CAM mounted on my hexapod, I'm implementing and evaluating genetic algorithms, simulated annealing, hill climbing, and simplex directly on-device.

The goal is to compare their performance and suitability for different vision tasks under tight memory and computational constraints, identifying which approaches are best suited to the robot's longer-term object detection and visual processing capabilities.

Tech Stack

C/C++ ESP32-CAM Embedded Systems

Key Features

  • Implementation and comparison of four search and optimization approaches: genetic algorithms, simulated annealing, hill climbing, and simplex.
  • Direct on-device execution on the ESP32-CAM, evaluating algorithm feasibility under limited memory and computational resources.
  • Integration with the hexapod's onboard camera, applying optimization methods to robotic vision tasks.
  • Comparative evaluation to identify which algorithms are best suited to different vision tasks and future object detection applications.
